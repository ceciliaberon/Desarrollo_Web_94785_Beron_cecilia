# Le Contes | Pastelería artesanal francesa 🥐

## Descripción del proyecto

**Le Contes** es un sitio web de una pastelería artesanal inspirada en la tradición francesa. Fue desarrollado como proyecto final del curso de Desarrollo Web de Coderhouse.

El objetivo es presentar la identidad de la pastelería, sus productos, sus ofertas y sus canales de contacto mediante una experiencia visual atractiva, intuitiva y adaptable a distintos dispositivos.

## Sitio publicado

🌐 **[Ver Le Contes en Vercel](https://desarrollo-web-94785-entrega9.vercel.app/)**

El proyecto utiliza GitHub para el control de versiones y Vercel para su publicación.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido semántico.
- **CSS3:** estilos visuales compilados desde Sass.
- **Sass (SCSS):** organización modular mediante variables, nesting, mixins, extend y partials.
- **Bootstrap 5:** sistema de grillas, navegación responsiva y carrusel.
- **AOS (Animate On Scroll):** animaciones durante el desplazamiento.
- **Git y GitHub:** control de versiones.
- **Vercel:** despliegue del sitio web.

## Secciones del sitio

El sitio está compuesto por cinco páginas:

1. **Inicio:** presentación de Le Contes y su propuesta de pastelería artesanal.
2. **Sobre nosotros:** información sobre la identidad y la historia de la pastelería.
3. **Menú:** presentación de productos y ofertas del mes.
4. **El espacio:** presentación del ambiente y la experiencia del local.
5. **Contacto:** información de contacto mediante correo electrónico y teléfono.
